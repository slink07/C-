# 🛒 Sistema de Pedidos em C#

Projeto de console desenvolvido em C# simulando um sistema de pedidos.

## 🚀 Funcionalidades

* Adicionar pedidos
* Ver carrinho
* Remover itens
* Tempo estimado de entrega
* Menu interativo

## 🧠 Tecnologias

* C#
* .NET

## ▶️ Como executar

```bash
dotnet run
```

## 📌 Exemplo de uso

1 - Adicionar pedido
2 - Ver carrinho
3 - Remover item
4 - Finalizar pedido
5 - Sair
